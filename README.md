# Film Border Studio

静态网页工具，用已有胶片边框素材给照片叠加边字。

## 功能

- 导入浏览器可解码的照片
- 选择 `135`、`645`、`66`、`67` 画幅
- 选择对应胶片边框
- 自动按画幅比例居中裁切照片
- 导出 PNG、JPEG、WebP
- JPEG/WebP 支持三档画质，PNG 为无损

## HDR 说明

GitHub Pages 是纯静态托管，浏览器端 Canvas 对 HDR、16-bit、HEIC/TIFF 等格式的保真读写取决于用户浏览器。本站会尽量使用浏览器支持的宽色域 Canvas；如果浏览器不支持，对应图片会按浏览器能力降级导出。
